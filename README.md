## 🛠️ Setup Instructions

### Prerequisites
- Node.js v18+
- Angular CLI v21

### Installation
```bash
npm install
```

### Development
```bash
ng serve
```

### Production Build
```bash
ng build --configuration production
```

## 🔑 Features
- User Registration with Email Verification
- Login with JWT & Refresh Token
- Role-Based Access Control (Admin/User)
- Fake Backend for local testing
- Guards & Auth Services
